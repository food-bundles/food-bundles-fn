# Customer type photos

Shown in a circle on sign-up ("What kind of business are you?") for customer
types that don't have their own picture yet (an admin uploads one in
Dashboard → Stock → Customer Types, and that one always wins).

Put a real photo of each kind of place here, with exactly these names:

| File          | Used for types named like…                      |
|---------------|-------------------------------------------------|
| hotel.jpg     | hotel, lodge, guest house, motel, resort        |
| school.jpg    | school, university, college, academy, institute |
| bar.jpg       | bar, pub, club, lounge                          |
| cafe.jpg      | café, coffee shop, bakery                       |
| hospital.jpg  | hospital, clinic, health centre                 |
| business.jpg  | anything else                                   |

Square photos look best (at least 600 × 600). Restaurants and caterers already
use the kitchen photos in ../kitchens, shops and markets use ../inzovu-mall.jpg.
Until a file is added, that type shows an icon instead.
